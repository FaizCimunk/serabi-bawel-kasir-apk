# 🥞 Serabi Bawel Kasir POS - Android APK

Aplikasi Android Native khusus meja kasir untuk brand **Serabi Bawel & Wedang Geprek** (10 Cabang).

## Fitur Unggulan
1. **Native Bluetooth Thermal Printer (58mm / 80mm):**
   - Mendukung protokol Bluetooth Classic SPP untuk printer thermal (Panda, Iware, Goojprt, RPP02N, POS-58, dll).
   - Auto-reconnect otomatis saat aplikasi dibuka.
2. **Auto Open Cash Drawer (RJ11):**
   - Mengirim sinyal trigger pembuka laci uang tunai otomatis saat pembayaran tunai.
3. **Realtime Cloud Synchronization:**
   - Terhubung langsung ke Database Cloud Supabase PostgreSQL dan Cloudflare Pages.
4. **Kiosk Mode:**
   - Layar terkunci pada interface kasir agar operasional toko aman dan terfokus.
